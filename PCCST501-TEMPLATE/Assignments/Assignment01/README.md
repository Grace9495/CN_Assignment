# Assignment

## Title
How the Internet Delivers a Web Page

## Objective
To understand the process that takes place when a user accesses a web page through a web browser. The assignment explains the roles of the TCP/IP protocol stack, DNS, HTTP/HTTPS, TCP, cookies, and the client–server architecture in establishing communication and delivering Instagram's web pages securely and efficiently.

## Solution
The assignment explains how www.instagram.com is accessed using networking protocols. DNS converts the domain name into an IP address, TCP establishes a reliable connection, and HTTPS securely exchanges data between the browser and Instagram's server. The TCP/IP protocol stack manages data transmission, while cookies store login sessions and user preferences. Instagram follows the client–server architecture to deliver web content efficiently.

## Output
The assignment successfully explained the TCP/IP protocol stack and demonstrated how DNS resolves the domain name into an IP address. It described how HTTPS enables secure communication, explained TCP's reliable connection process, and identified Instagram as a client–server application. It also compared HTTP and FTP, explained the role of cookies, and illustrated the complete process of loading the Instagram webpage.

## Conclusion
This assignment provided an understanding of how networking protocols work together to access Instagram securely and efficiently. DNS, TCP, HTTPS, the TCP/IP protocol stack, cookies, and the client–server architecture each play an important role in delivering web content and ensuring a smooth user experience
